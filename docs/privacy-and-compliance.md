# 隐私与合规说明

## 1. 适用范围与当前状态

本文规定“苏华食养状态观察卡”处理用户照片及生成内容时的最低要求。照片属于敏感个人信息，应按更严格标准处理。

基线 `main@f10a402` 目前仅有前端初始化页面和服务端健康检查，尚未实现照片上传、同意、转发、生成、清除或用户权利流程。以下要求属于开发和上线门槛，不能表述为当前已经实现。

## 2. 处理目的和禁止用途

照片的唯一目的，是按用户主动选择的信息生成视觉观察卡。不得将照片用于：

- 医学诊断、健康风险、疾病、体质、营养状况或心理状态推断；
- 面相、命运、性格、能力、民族等推断；
- 身份识别、账号画像、广告定向、模型训练或与其他数据集关联；
- 未经另行明确同意的产品分析或二次用途。

产品建议只能基于用户主动选择或输入的信息生成。不得把图像模型输出包装为从面部观察得到的健康结论。

## 3. 明确同意

发送照片前必须取得单独、明确、可证明的同意：

- 同意框默认不勾选，不能与服务条款或营销同意捆绑。
- 在同意动作附近说明处理目的、数据类型、服务端转发、第三方服务商、保存期限和撤回/删除渠道。
- 未同意时不得上传照片，不得通过预加载、预检接口或分析 SDK 发送照片。
- 每次重新选择照片后，应重新确认本次照片的发送；同意记录至少包含版本、时间和请求 ID，但不得记录照片本身。
- 拒绝同意不应影响用户浏览非上传内容。

建议的简明提示文案：

> 我同意将所选照片发送给图片生成服务商，仅用于生成本次观察卡。我已了解原图和生成图的处理、保存及删除说明。

该提示不能替代完整隐私政策。

## 4. 数据最少化与技术要求

- 只收集生成所必需的一张照片和用户主动选择的状态，不收集身份证号、精确位置、病史等无关信息。
- 前端先校验文件类型和 10 MB 上限；服务端必须再次校验实际文件类型、大小和字段白名单。
- 浏览器只调用同源应用服务端，由服务端转发至上游；禁止浏览器直连上游，禁止向浏览器提供 API Key。
- 原图不落盘：应用服务端不得将原图保存到磁盘、数据库、对象存储、备份、持久队列或日志。上传应采用受限内存流，并在完成、失败或超时后释放。
- 不记录 multipart 请求体、图片内容、完整 prompt、API Key、签名 URL 或可识别个人的数据。错误监控和 APM 需关闭相关正文采集并做字段脱敏。
- 前端照片预览仅使用本地对象 URL 或等效本地机制，不上传到分析、埋点或错误监控服务。
- 用户点击“重新选择照片”或“清除照片”时，必须撤销对象 URL，清空文件引用和前端预览。

清空前端预览只影响用户设备当前页面，不代表已发送数据已从服务商删除。界面和客服答复必须明确这一区别。

## 5. 上游与生成图保存说明

- 根据当前提供的上游文档声明：**原图在处理完成后 10 分钟删除**。这是服务商的文档声称，不是本项目已独立验证的事实。
- 上线前必须保存对应文档版本、条款链接和核验日期，并通过合同、数据处理协议或技术测试确认适用范围、起算点、失败请求处理和备份删除规则。
- 生成图可能由服务商托管。上线前必须确认托管位置、访问控制、URL 是否可猜测、保存期限、删除接口、跨境传输和分包商情况，并在隐私政策中如实披露。
- 在上述事项未确认前，不得使用“生成图不会保存”“立即删除”“永久私密”等绝对表述。
- 若产品自身未来保存生成图，必须另行说明目的、期限和删除方式，并重新评估同意与安全措施；当前规范不授权该保存行为。

## 6. 用户权利与撤回

- 用户在发送前可随时重新选择并清空前端预览。
- 发送后，应提供可操作的访问、更正、删除、撤回同意和投诉渠道，并说明服务商托管生成图的删除流程。
- 撤回同意不影响撤回前处理的合法性，但应停止后续非必要处理。
- 用户请求处理应有身份核验、内部工单、完成时限和服务商联动记录，且核验数据同样遵循最少化。

这些渠道和流程在基线中尚未实现。

## 7. 文案与内容合规

允许使用“生活状态”“食养灵感”“日常建议”“非医疗”等中性表达。禁止出现或暗示：

- 从脸色、五官、皮肤或照片推断疾病、气血、脏腑、体质、营养缺乏或心理状态；
- “诊断、治疗、处方、治愈、疗效保证、疾病风险预测”等医疗承诺；
- “面相、看脸识病、命运、性格判断”等推断；
- 鼓励用户停止就医、停药或用生成内容替代专业意见。

若用户主动选择的状态涉及持续不适，产品只能给出寻求合格专业人员帮助的通用提示，不作分诊或紧急程度判断。

## 8. 上线前必须补齐

- 发布完整隐私政策，列明运营主体、处理目的、敏感个人信息、处理方式、保存期限、第三方服务商、用户权利和投诉渠道。
- 填入并验证真实有效的运营主体名称、联系邮箱/电话及必要的注册地址或其他法定联系方式。**当前仓库未提供真实联系方式，文档不得虚构占位信息为真实信息。**
- 完成服务商尽调、数据处理协议、跨境与分包商评估，以及原图 10 分钟删除声明的证据留存。
- 配置生产密钥、密钥轮换、最小权限、访问审计、限流、内容安全、日志脱敏、监控和事件响应。
- 完成隐私影响评估、未成年人使用规则、用户权利工单流程和数据泄露应急预案。
- 对实际网络请求做上线验收，确认照片只流向声明的应用服务端和服务商，且无分析 SDK、日志或监控旁路采集。
